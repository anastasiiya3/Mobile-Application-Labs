# Mobile-Application-Labs

Android source projects, labs 1–6 (Kotlin/XML). Open each Lab folder separately in Android Studio using JDK 17 and SDK 35. Lab 6 requires a Firebase project, Email/Password authentication, Cloud Firestore, google-services.json in app/, deployed firestore.rules and admin role assigned through the Firebase console. No credentials included. Reconstructed source; Android build/runtime not verified.
